# Blood Donation Management System - Software Testing Assignments

## 1. Purpose

This document assigns software testing tasks to four team members and records the test cases in the requested format. Three members receive easy, explainable workflows (Login, Register, Appointment Booking) and the fourth member receives the remaining Admin/Inventory feature.

## 2. Testing Assignment Overview

- Member 1: Login Function
- Member 2: Register Function
- Member 3: Appointment Booking Function
- Member 4: Inventory Management / Admin Dashboard Function
